⚡ Set up your tracker

Set up Firebase for free cross-device sync (phone + laptop + anywhere). Takes ~5 minutes. Or skip and use offline on one device.

1
Go to console.firebase.google.com → Create project → name it anything → disable Analytics → Create
2
Left sidebar → Firestore Database → Create database → Start in test mode → choose any region → Enable
3
⚙️ Project Settings → General → scroll to "Your apps" → click </> (Web) → Register → copy the firebaseConfig object → paste below
